# Section 03: CTA Bar Spotlight

## Overview
A high-converting 3-button call-to-action bar situated immediately beneath the hero video banner. It provides high-visibility routing to the most common visitor paths.

## Layout & Buttons
```text
[ How to apply (/admissions) ]   [ Contact Us (/contact-us) ]   [ Visit Our Campus (/visit) ]
```

## Visual Design & Behavior
- **Bar Background**: Dark neutral or subtle maroon accent container.
- **Button Tokens**:
  - Default: Pure white background `#ffffff`, dark charcoal bold text `#111111`, sharp border.
  - Hover / Active: Chicago Maroon fill `#800000`, white text `#ffffff`, border turns Maroon `#800000`.
  - Micro-interaction: Subtle `translateY(-2px)` elevation with smooth 0.25s cubic-bezier ease.
- **Mobile Responsive**: Buttons stretch to 100% width on mobile screens (stacked vertically with 12px gap).
